# 展覽引用資料

查核日期：2026-10-20。本展以台灣政府資料開放平臺為入口，引用機關原始報告。以下數據描述不同年份、不同觀察對象，分開呈現，不拼接成同一群家庭或孩子。

## 2022 年國小學齡兒童費用

- 機關：衛生福利部。
- 原始資料：[111 年兒童及少年生活狀況調查・兒童篇](https://www.mohw.gov.tw/dl-86168-9a466094-0c39-4ed1-b95e-fdbc74e7c28e.html)。
- 定位：表 24，印刷頁 227–228，PDF 第 239–240 頁。
- 對象與單位：國小學齡兒童；一名兒童每月補習及課後照顧費用，新臺幣元。由家長或主要照顧者填答。
- 分母：全體學齡兒童，包含未付費者；比率採官方公布值，四捨五入後合計 100.1%，不正規化為 100%。
- 費用級距：未付費 12.9%；1–4,999 元 27.3%；5,000–9,999 元 37.5%；10,000–14,999 元 14.4%；15,000–19,999 元 5.0%；20,000–24,999 元 1.8%；25,000–29,999 元 0.8%；30,000 元以上 0.4%。

「未付費」不代表沒有學習資源、不重視教育或無力負擔。費用也不直接代表品質。已檢查的公開表未提供家庭經濟條件與這些費用的交叉，亦沒有呈現單一課後班的服務時間與品質。

## 2025 年家庭教育支出

- 機關：行政院主計總處。
- 原始資料：[114 年家庭收支調查報告](https://www.stat.gov.tw/News_Content.aspx?n=3908&s=236588)、[第 6 表 ODS](https://ws.dgbas.gov.tw/001/Upload/463/relfile/11530/236588/77.ods)。
- 平臺入口：[所得五等分位家庭之可支配所得、消費與儲蓄](https://data.gov.tw/dataset/6565)；展覽數值取自機關原始第 6 表。
- 對象：全體家庭，包含沒有在學成員的家庭；依每戶可支配所得由低至高分成五組。
- 單位：每戶全年平均教育支出，新臺幣元；每戶人數的單位為人。
- 原始位置：工作表「工作表」，C11:G11 為每戶人數，C67:G67 為教育支出。

| 所得組          | 每戶人數（人） | 教育支出（元／年） |
| --------------- | -------------: | -----------------: |
| 第 1 組（最低） |           1.55 |              1,392 |
| 第 2 組         |           2.08 |              6,227 |
| 第 3 組         |           2.70 |             15,777 |
| 第 4 組         |           3.35 |             33,450 |
| 第 5 組（最高） |           3.77 |             55,147 |

各組家庭人口結構不同；此表未提供各組在學人數，不能當成相同就學需求下的每名學生資源比較。人口包含成年人等成員，不能直接替代學生人數。所得統計包含自用住宅設算租金等項目，與現金帳單有所不同；平均值不能推算每個家庭應有的收入。

## 引用與檢查方式

網站數值集中於 `src/data.js`。`tests/fixtures/official-tables.json` 是從已核對的研究表抽出的公開數值快照，保留機關、表號與觀察單位，供測試獨立對照。更新統計時應重新核對原表，同時更新快照與來源定位。

網站的情境與插畫為原創策展表達，不是特定家庭的紀錄。原始政府報告以官方連結提供；本 Repo 不重新發布整份報告或私人的試讀紀錄。CSV 為本展引用數值，並附年度、對象、單位及來源。

本展與聯合國 [SDG 4.5](https://sdgs.un.org/goals/goal4) 及 [SDG 10.2](https://sdgs.un.org/goals/goal10) 的議題相關。支出統計不等於官方指標 4.5.1，現有數據仍不足以證明經濟分化造成教育資源差距，或差距正在擴大。
