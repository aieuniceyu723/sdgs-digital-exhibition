## 已實作

- 帳單紙張、收據及資料檔案為視覺主題；暖白、炭黑與朱紅配色，支援手機、平板與桌面。
- 開場明示家庭收入與教育資源問題；收據為 2025 年第三所得組的統計摘錄，清楚標示不是個別家庭案例。
- 4 種生活情境，切換費用、時間、服務與需求的說明；不估算個人收入或替家庭評分。
- 2022 年兒童每月費用：8 個可操作區間、40% 的共同圖表尺度、公布值及未付費解讀。
- 2025 年家庭比較：5 個所得組、教育年支出及每戶人數；在學人數未知一直保留在畫面中。
- 來源說明對話框、官方報告連結、2 份帶統計年度／對象／單位／來源的 CSV 下載。
- 離場問題切換、章節導覽與閱讀進度；選擇只存在頁面記憶體，重新整理即重設。
- GSAP／ScrollTrigger 入場、資料圖表及輕量捲動效果；支援系統減少動態偏好與頁尾手動切換。
- 跳至主要內容、可見焦點、原生按鈕及 details、即時文字更新、Escape 關閉對話框及焦點歸還。完整數據表為原生 HTML，即使 JavaScript 未執行仍可讀取。

## 執行與建置

```sh
export PATH="$PWD/.tools/bin:$PATH"
pnpm dev
pnpm test
pnpm format:check
pnpm build
pnpm preview
```

`pnpm build` 以相對資源路徑輸出至 `dist/`。本機開發只綁定 `127.0.0.1`，以啟動命令實際顯示的網址為準。

正式網站：[https://aieuniceyu723.github.io/sdgs-digital-exhibition/](https://aieuniceyu723.github.io/sdgs-digital-exhibition/)。[首次部署工作流程](https://github.com/aieuniceyu723/sdgs-digital-exhibition/actions/runs/39423752232)已成功，網站產物對應程式提交 `5c8383087ac1d64bde1ee0ebfd6f504aa3ed5e7e`。後續僅更新 Markdown 不重新建置網站。

## 保留的限制與後續

2022 年兒童分布與 2025 年全體家庭平均沒有拼接；費用不作為學習品質替代指標。現有資料尚不足以證明經濟分化造成教育資源差距或差距正在擴大。

後續可安排外部觀眾試看，補強經濟條件與學童資源交叉資料；Google 回饋串接依使用者新指示另行進行。
